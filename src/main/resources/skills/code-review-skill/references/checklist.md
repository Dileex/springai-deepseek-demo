# Java 代码审查检查清单

## Bug 和边界条件

- 参数是否可能为 null
- 集合是否可能为空
- 字符串是否可能为空白
- 下标、分页、金额、数量是否有边界
- 时间和时区是否明确

## 安全风险

- 是否硬编码密码、Token、API Key
- 是否缺少权限校验
- 是否暴露敏感字段
- 是否存在 SQL 注入或命令注入风险
- 是否把异常栈直接返回给用户

## 异常和日志

- 是否吞掉异常
- 是否只 catch `Exception` 却不处理
- 日志是否包含必要上下文
- 日志是否泄露敏感信息

## 可维护性

- 方法是否过长
- 分支是否过深
- 命名是否表达业务含义
- 是否把业务规则写成魔法值
- 是否缺少关键注释

## 测试建议

- 正常输入
- 空值输入
- 非法输入
- 异常分支
- 权限不足
- 并发或重复请求
